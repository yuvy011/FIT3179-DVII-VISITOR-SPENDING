# Follow Australia’s travel dollar

By Utkarsh Vaishnav · FIT3179 · Updated 22 October 2026

A single-page visitor-spending story for the average Australian reader. Fifteen charts form three chapters of five figures: spending baskets, visitor markets, and geography/recovery.

## Run locally
From this folder run `python3 -m http.server 8000`, then open http://localhost:8000. Opening index.html directly may block local data requests.

## Publish
Upload the contents of this folder to the existing GitHub Pages repository. Keep index.html at the published root and retain json/, data/, js/, css/ and vendor/. Check the published page and every Chart JSON link. This ZIP does not publish changes automatically.

## Submission
Provide the public website URL, the URL of your original hand-drawn sketch PDF, and the required domain/who/what/why/how rationale in Moodle. The sketch is not included in this project and must be supplied by the author. Prepare to explain marks, channels, sources, denominators and interactions at interview.

## Sources and scope
ABS Tourism Satellite Account, ABS overseas arrivals, and TRA IVS/DoTS provide the spending and arrival series. Each chart specifies its period, units and source. Tourism-region boundaries are from TRA 2026 based on ABS ASGS 2021. Values are nominal. Full-trip expenditure, spending in Australia, arrival movements and visitor-nights are distinct measures.

Figure 12 contains five tourism-region boundaries but only two published spending aggregates: Hobart and the South and the combined remainder. No individual spending estimates have been assigned to the four remaining regions.

Figure 07 uses ranked education-spending bars; Figure 10 is a category budget-share heatmap.

See CHART_MATRIX.md for the displayed chart inventory and data/ for data and provenance. The source workbook is included for verification and is not downloaded by charts.
